# Skreenshot

Record it once. Skreenshot makes it polished.

Screen recording with smart zoom, cursor effects, captions and on-device transcription. Your recordings stay on your computer.

## Download

**[Download Skreenshot for Windows](https://github.com/ikramsakib/skreenshot-releases/releases/latest)**: open the latest release and run `Skreenshot_<version>_x64-setup.exe`.

Needs Windows 10 (1903) or Windows 11 on a 64-bit PC from about 2013 or later. Windows may show "Windows protected your PC" the first time; choose **More info**, then **Run anyway**.

## Updates

Install once. Skreenshot checks for new versions by itself and asks before updating. You can also check in **Settings → General → Updates**.

A Mac version is planned.
